# train-and-evaluate-a-tool-using-agent-in-pytorch
Train a small language model to use tools, run it as an agent, and measure how good it really is. Write a calculator and a lookup tool, a text format for tool calls, and the loop that parses a call, runs the tool and feeds the result back, with a checker for the final answer. Collect trajectories from a teacher, keep the ones the checker accepts,…
